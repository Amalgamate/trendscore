# Presence & Movement v2 — Screen Map

Every operational learner screen should share a side panel: latest trusted state, confidence/as-of time, active exceptions, today's expectations and timeline. It links to source records rather than duplicating them.

| Screen | Purpose/components | Actions/relationships |
|---|---|---|
| Presence & Movement Overview | state counts, expected/confirmed/exceptions, filters | opens exception queue, timeline and source register; replaces attendance-only presence dashboard later. |
| Exception Queue | evidence, owner, SLA, status | acknowledge, assign, resolve/dismiss with reason. |
| Movement Register | factual events by learner/location/device/time | filters; opens source/audit record. |
| Learner Timeline | facts, state intervals, expectations, corrections | existing timeline evolves; source owns corrections. |
| Daily/Class Attendance | defined-period register/completion | mark/correct attendance; distinct from entry/transport. |
| Staff Attendance | shifts/clock compliance | HR-owned, linked to staff timeline. |
| Biometric Authority | enrollment/consent, devices, feed, bridge | configure terminal purpose/location and review evidence. |
| Boarding Overview | roll-call and exeat compliance | opens dorms, allocation, roll call, dining/prep, exeat. |
| Transport Overview | route/trip/manifest/exception health | opens stops, fleet, scan mode, GPS, reports. |
| Routes & Stops | ordered stops/windows | changes are effective-dated and feed future manifests. |
| Trips & Manifest | daily expected/actual passenger run | start/complete, board/alight, supervised override. |
| Driver Scan Mode | offline QR/ID/manual capture | creates only trip facts and exceptions. |
| GPS Live Location | vehicle telemetry/ETA/geofence | clearly separates vehicle evidence from learner evidence. |
| Parent Presence View | safe child state/timeline | read-only and privacy-filtered. |

Move legacy Hostel Allocation navigation under Boarding only after parity; retain Attendance Reports/Settings and raw Biometric administration as distinct screens.
