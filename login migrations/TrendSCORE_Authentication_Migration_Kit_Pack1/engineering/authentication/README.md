# TrendSCORE Authentication Migration Kit

Purpose: Safely migrate TrendSCORE to an identity-first, phone + OTP authentication system.

Scope:
- Authentication
- Identity
- Roles
- Sessions
- Devices
- PWA login
- Notifications related to authentication

Out of Scope:
- Finance
- Assessment
- Attendance
- UI redesign unrelated to login

Rule: One phase at a time. Never skip phases.

Important:
- The migration kit is split across packs.
- Always read `login migrations/START_HERE.md` first.
- Pack 1 contains the control documents.
- Pack 2 contains Phase 0.
- Pack 3 contains Phase 1.
