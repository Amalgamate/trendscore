# Master Prompt

Before changing any authentication code:

1. Read `RULES.md`.
2. Read `LOCK_FILE.md`.
3. Read `STATUS.md`.
4. Read `PROGRESS.md`.
5. Read the active phase document and checklist.
6. Work ONLY on the active phase.
7. Preserve backward compatibility.
8. Refactor before replacing.
9. Remove duplicate code only when the active phase allows it.
10. Do not modify unrelated modules.
11. Update `STATUS.md` and `PROGRESS.md`.
12. Update the active phase checklist.
13. Produce or update the active phase report with:
   - Summary
   - Risks
   - Tests
   - Rollback plan
   - Acceptance criteria status
   - Next phase readiness
Stop when the current phase is complete.
