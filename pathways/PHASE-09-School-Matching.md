# PHASE 09 — School Matching

## Objective
Recommend senior schools aligned to each learner's pathway, subject combination, goals and family preferences.

## Matching Inputs
- TrendScore recommendation
- Pathway and track
- Subject combination
- Academic readiness
- Parent preferences
- Learner preferences
- Counsellor recommendations

## School Directory
- Official profile
- County / Sub-county
- Public / Private
- Day / Boarding
- Gender
- Pathways offered
- Subject combinations
- Facilities
- Verification status
- Last verified

## Matching Pipeline
1. Validate eligibility
2. Match pathway
3. Match subject combination
4. Apply family filters
5. Rank by fit
6. Explain every recommendation

## Outputs
- Dream
- Target
- Safe
- Local
- Comparison report

## Governance
Reference data must be versioned and auditable.
