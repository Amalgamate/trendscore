# PHASE 08 — Career Explorer

## Objective
Help learners understand careers before selecting pathways, subject combinations and schools.

## Knowledge Structure
Career
→ Career Family
→ Required Skills
→ Recommended Pathway
→ Track
→ Subject Combinations
→ University Routes
→ TVET Routes
→ Alternative Careers

## Career Profile
- Description
- Daily work
- Skills required
- Subjects required
- Entry pathways
- Growth outlook
- Related careers

## Learner Features
- Browse careers
- Save favourites
- Compare careers
- Discover related careers
- Explore education routes

## Recommendation Logic
Career suggestions combine:
- Existing TrendScore recommendation
- Academic strengths
- Interests
- Competencies
- Parent input
- Counsellor guidance

## Future Expansion
Support scholarships, internships, labour-market insights and employer partnerships.
