# PHASE 11 — AI Recommendation Engine

## Objective
Define how AI enhances, but never replaces, the existing TrendScore recommendation engine.

## Responsibilities
- Explain recommendations in plain language.
- Generate personalized guidance.
- Suggest careers and learning actions.
- Highlight strengths, risks and alternatives.
- Support counsellors with summaries.

## AI Must Not
- Override scoring logic.
- Change pathway outcomes without evidence.
- Make final approval decisions.
- Produce unexplained recommendations.

## Recommendation Pipeline
1. Assessment data
2. Existing scoring engine
3. Rule validation
4. Confidence calculation
5. AI explanation
6. Human review
7. Final recommendation

## Confidence
Display confidence levels (High, Medium, Low) with contributing evidence rather than hidden formulas.

## Governance
- Prompt versioning
- Audit AI responses
- Human override
- Safety review
- Continuous evaluation
