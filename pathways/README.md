# Pathway Decision Centre

> TrendScore's Intelligent Pathway, Career and Senior School Decision Platform

## Overview

The Pathway Decision Centre is a core TrendScore module that transforms learner assessment data into guided decisions about pathways, careers, subject combinations and senior school selection.

It builds on the existing recommendation engine and introduces collaborative decision making between students, parents, counsellors and schools.

## Objectives

- Explain every recommendation.
- Support informed family decisions.
- Integrate with existing TrendScore modules.
- Remain transparent and evidence-based.
- Support future Ministry-aligned updates.
