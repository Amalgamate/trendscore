# PHASE 06 — Parent Experience

## Objective
Enable parents to participate constructively in pathway and school decisions.

## Entry Point
Parent App → My Child's Future

## Parent Journey
1. Review learner profile
2. Read recommendation explanations
3. Add family preferences
4. Set constraints
5. Compare schools
6. Discuss with learner
7. Review counsellor notes
8. Approve or request review

## Parent Preferences
- Budget
- Boarding / Day
- Preferred counties
- Distance
- Faith preferences (optional)
- Special support needs
- Family priorities

## Permissions
Parents may:
- Comment
- Save preferred schools
- Compare options
- Approve decisions

Parents may not:
- Change recommendation scores
- Override counsellor approval
- Edit learner assessment data

## Notifications
- Recommendation ready
- Student requests review
- Counsellor feedback
- Decision awaiting approval
